# رفيق القراءة

تطبيق Flutter عربي لقراءة ملفات PDF مع مكتبة محلية، حفظ آخر صفحة، علامات مرجعية متعددة، تكبير الصفحة، وتمرير تلقائي بسرعة قابلة للتعديل.

## البناء

يعمل GitHub Actions تلقائياً عند كل تحديث على فرع `main`. بعد نجاح مهمة **Build Rafiq Alqiraa APK** نزّل الملف من قسم Artifacts باسم `rafiq-alqiraa-release-apk`.

## ملاحظات الإصدار الأول

- عرض PDF الأصلي مع تكبير/تصغير بالإصبعين.
- فتح ملفات PDF من الهاتف وإضافتها للمكتبة.
- حفظ موضع القراءة وعلامات مرجعية محلياً.
- انتقال تلقائي بين الصفحات مع التحكم بالسرعة.
- إعادة تدفق النص وOCR للملفات المصورة ليستا ضمن هذه النسخة الأولية بعد.
